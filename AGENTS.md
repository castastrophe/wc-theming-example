# wc-theming-example

Intended as a small example site demonstrating dynamic theming of web components.

## State of this repo

`main` holds `README.md` and `LICENSE` and nothing else: one commit, "Initial
commit". There is no source, no build, and no package manifest here yet.

Unfinished work lives on the **`feat-initialize-repository`** branch. Before starting
anything in this repo, check that branch out and see what's already there; building
from `main` means rebuilding whatever it already contains.

If the branch turns out to be stale and the answer is to start over, that's a decision
for the maintainer, not an assumption to act on.

Never add AI attribution to a commit or a PR: no `Co-Authored-By` trailer, no
"Generated with …" footer, no session URLs.

## Prose style

Prose in this repo (README, commit bodies, PR descriptions) follows the
[style guide](https://github.com/castastrophe/.github/blob/main/AGENTS.md#style-guide):
sentence-case headings, `&` over "and", `:` over em dashes.
